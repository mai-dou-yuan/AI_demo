快速开始

运行环境：Linux · Python 3.11 · Node.js 24 · Conda。

首次安装？点击下方「首次使用」展开完整步骤。已有环境可直接运行启动命令。

🔹 首次使用：安装依赖并准备配置　点击展开步骤

 在项目根目录执行，无需重新创建前端项目： 
conda create --prefix ./.conda/ai-brain -c conda-forge python=3.11 nodejs=24 pip -y
conda activate "$PWD/.conda/ai-brain"
python -m pip install -r requirements.lock.txt
cd frontend
npm ci
cd ..
cp -n .env.example .env
chmod 600 .env
编辑本地 `.env` 配置聊天模型、Embedding 和搜索服务。聊天与 Embedding 的凭据独立配置，字段说明见 [.env.example](.env.example)。 完整安装步骤与镜像源选择见 [安装书](安装书.md) 和 [服务器迁移说明](服务器迁移安装说明.md)。

启动工作空间：

bash scripts/dev.sh

打开 http://localhost:3000。首次启动后，在另一终端查看随机登录凭据；登录后必须修改密码：

cat storage/initial-login.txt
🔹 局域网访问与常用命令 · 点击展开 
# 同一路由器访问：停止旧服务后执行，使用终端打印的地址
bash scripts/dev.sh lan

# 在服务器终端重置登录账号或密码
.conda/ai-brain/bin/python scripts/account.py

# 检查配置，不调用外部服务
.conda/ai-brain/bin/python scripts/check_services.py

# 业务、安全回归测试与前端类型检查
bash scripts/test.sh
LAN 模式使用 HTTP，会清空公网 HTTPS Origin，仅适合可信局域网临时访问。按需对局域网放行 `3000/TCP`，不开放后端 `8000`。 邮件在「待办事项 → 邮件设置」配置；支持填写发件邮箱、SMTP 授权码和收件人。

数据与部署

业务记录与文件保存在本机 storage/；启用模型、Embedding、搜索和邮件时，所需内容会发送到对应外部服务，并非完全离线运行。

当前采用单账号、单进程部署，业务 API 与下载接口统一鉴权。.env 和运行数据不提交 Git；本地密钥文件未做磁盘级加密。公网运行需使用生产构建、HTTPS 和入口访问控制，详见 登录与安全说明。

当前使用边界 - PDF 需要文字层，尚未启用 OCR。 - 聊天采用最近消息窗口与长度截断，尚未实现自动上下文压缩。 - 服务重启后，中断的后台任务需要手动重试。 - 邮件发送给配置的收件人，不自动将责任人名称映射为邮箱。 - 自动化测试不代替外部服务、浏览器与公网部署验收，模型输出和引用内容仍需核对。
