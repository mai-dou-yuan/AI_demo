# 知识库 PDF 测试资料

已在线核对以下官方 PDF 的文字解析结果与页数。当前执行沙箱无法直接下载，因此此目录先提供来源清单、下载脚本与核对题；**原始 PDF 是否下载成功，以 `download-report.json` 和实际文件为准**。资料保留原文，仅用于检索测试，不代表内容已更新为今天的资料。

## 1. 下载

在项目根目录执行，无需安装新依赖：

```bash
.conda/ai-brain/bin/python scripts/download_knowledge_samples.py
```

默认直连，不继承终端的 SOCKS 代理。若本机确实有 `10808` HTTP 代理，可改为：

```bash
PDF_DOWNLOAD_PROXY=http://127.0.0.1:10808 \
  .conda/ai-brain/bin/python scripts/download_knowledge_samples.py
```

脚本下载到本目录，检查 PDF 格式、页数和文字层，记录大小与 SHA-256，不自动上传、不调用外部模型。若自动下载失败，点击下方链接用浏览器另存为 PDF，再通过知识库页面上传。

## 3. 如何测出是否真的用了知识库

1. 先确保 `.env` 的 `EMBEDDING_BASE_URL/EMBEDDING_API_KEY/EMBEDDING_MODEL` 有效；DeepSeek 聊天和搜索配置不会自动补齐向量服务。
2. 关闭聊天的「联网搜索」，新建会话；先只上传一份文件，等待文件状态为「可用」。
3. 在知识库点击「用于对话」，复制上面的核对题。回答应带所选文件名、正确页码及可打开的原文链接。
4. 不只看答案是否正确。上述问题本身属于常识，模型可能凭已有知识答对；需同时检查「正在检索」、来源卡片及原文页码。
5. 测试未提供信息：选中 WHO 海报，问「这份 PDF 指定了哪个洗手液品牌和售价？」。文件没有这些信息，不能编造品牌、价格或页码。
6. 进阶比较题：同时上传 WHO 和中文指南，问「WHO 海报的整个洗手流程时长，与中文指南的双手搓擦时长分别是多少？请逐份引用，不要混为一谈。」核对为 WHO **40–60 秒**（第 1 页）与中文指南搓擦**至少 20 秒**（第 16 页），两个数值描述不同阶段。

全部是普通 PDF 原文件，上传后会按正常业务调用 Embedding 并存入本地知识库。若上传状态失败，先查看文件错误和最近任务，不要把模型能回答常识当成 PDF 检索已经成功。
